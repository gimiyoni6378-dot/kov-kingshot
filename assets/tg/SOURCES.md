# TG rank icons

Source page: https://kingshotdata.kr/ko/guides/truegold.html
Downloaded on 2026-11-18 from https://kingshotdata.kr/img/icons/truegold_level_{1..8}.webp

Each is the original 48 × 48 WebP image, stored locally without editing or resizing. Images are used as decorative badges beside the website activity rank on the KOV member page.

The source page provides TG1–TG8 images. TG9 and TG10 are text-only on that page, and the corresponding image endpoints returned HTTP 404. These tiers use text badges in KOV until source images become available. Do not assign a different TG tier's artwork to them.
