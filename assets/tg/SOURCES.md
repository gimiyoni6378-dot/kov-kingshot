# TG rank icons

Source page: https://kingshotdata.kr/ko/guides/truegold.html
Downloaded on 2026-11-18 from https://kingshotdata.kr/img/icons/truegold_level_{1..8}.webp

Each is the original 48 × 48 WebP image, stored locally without editing or resizing. Images are used as decorative badges beside the website activity rank on the KOV member page.

The source page provides TG1–TG8 images. TG9 and TG10 are text-only on that page, and the corresponding image endpoints returned HTTP 404. TG9 and TG10 now use the user-approved generated variation described below.

## TG9 / TG10 custom variations

`tg-9-10.png` is the user-approved image generation edit of the TG8 reference with the central numbers changed to 9 and 10. It is a custom KOV variation, not original game artwork for these tiers. The original generated PNG is retained intact; CSS sprite positioning displays each badge at 48 × 48 without altering the image file.
